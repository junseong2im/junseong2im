Original pixel-art banner (`banner.png`) created for this GitHub profile. `hero.svg` layers animation on top of it.

Every other SVG here is generated by `scripts/build.py` (`python scripts/build.py`). The stats card is rebuilt daily by
`.github/workflows/stats.yml` and published to the `output` branch.

- Text: [Galmuri](https://github.com/quiple/galmuri) pixel fonts by Lee Minseo, SIL Open Font License 1.1, rendered to paths.
- Technology icons: [Simple Icons](https://simpleicons.org) (CC0), vendored in `scripts/icons/`.
