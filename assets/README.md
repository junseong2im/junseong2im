Every SVG here is generated by `scripts/build.py`, in a dark and a light variant (`*-dark.svg`, `*-light.svg`)
that the README switches between with `<picture>`.

- `python scripts/build.py` rebuilds the static figures in this folder.
- `.github/workflows/live.yml` rebuilds the data-driven cards (project cards, citations, contributions,
  languages, blend demo) daily, publishes them to the `output` branch and refreshes the activity log in the README.
- `.github/workflows/scent.yml` runs the blend demo: an issue titled `scent|<note>` adds that note to the blend.
