Original pixel-art banner (`banner.png`) created for this GitHub profile. `hero.svg` layers animation on top of it.

Every other SVG is generated by `scripts/build.py`:

- `python scripts/build.py` rebuilds the static assets in this folder (`*-m.svg` are the phone layouts).
- `.github/workflows/live.yml` rebuilds the data-driven cards (stats, recent quests, project cards, research card)
  every day and publishes them to the `output` branch.
- `.github/workflows/scent.yml` runs the Scent Lab game: an issue titled `scent|<note>` adds that note to the bottle.
