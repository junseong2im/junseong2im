# Profile artwork

Original SVG layout, illustrations and Korean copy for this GitHub profile.
All graphics are self-contained; no tracking badges, analytics endpoints or external image dependencies are used.

Technology logo paths for Python, PyTorch, NumPy, React, Next.js, PostgreSQL, Git, Google Colab, LaTeX and TypeScript are from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Product names and logos remain trademarks of their respective owners. RDKit and VS Code tiles use generic molecule/code illustrations rather than official logos.

The hero's decorative orbit animation respects `prefers-reduced-motion`. Separate compact and dark variants keep the artwork readable across screen sizes and themes.
